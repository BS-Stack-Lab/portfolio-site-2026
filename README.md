## 💡 About

**애플스토어의 UI/UX 철학**에서 영감을 받아 제작한 개인 포트폴리오입니다.

단순한 정보 나열이 아닌, 방문자가 **직접 경험하는** 공간을 목표로 설계했습니다.
Glassmorphism과 Backdrop Blur를 활용한 시각적 계층감, 리드미컬한 인터랙션,
그리고 모바일까지 고려한 하이브리드 터치 이벤트를 통해 완성도를 높였습니다.

---

## ✨ Key Features

| 기능 | 설명 |
|------|------|
| 🧩 **Responsive Bento Grid** | 데스크톱부터 모바일까지 최적화된 유연한 레이아웃 |
| 🪟 **Interactive Modals** | 프로젝트·기술 스택 상세 정보를 담은 고해상도 모달 시스템 |
| 🍎 **Apple-style Interactions** | Glassmorphism, Backdrop Blur, 부드러운 Hover 효과 |
| 📱 **Touch-Friendly** | 모바일 터치 이벤트를 고려한 하이브리드 인터랙션 설계 |

## 🛠 Tech Stack

### Core
- **Next.js 14** — App Router 기반 서버 컴포넌트 활용
- **React** — 컴포넌트 단위 UI 설계
- **Tailwind CSS** — 유틸리티 퍼스트 스타일링

### Tools & Deployment
- **Vercel** — CI/CD 및 배포
- **Figma** — UI/UX 디자인 프로토타이핑
- **Gemini AI** — 코드 아키텍처 및 카피라이팅 보조

## 📁 Project Structure

```
MY-PORTFOLIO/
├── app/                    # Next.js App Router (Layout, Page)
├── components/             # 재사용 가능한 UI 컴포넌트
│   ├── AboutMe/            # 자기소개 섹션
│   ├── Header/             # 글로벌 네비게이션 시스템
│   ├── Hero/               # 메인 히어로 섹션
│   ├── InfoBanner/         # 기술 스택 전 설명 섹션
│   ├── ProjectBanner/      # 프로젝트 전 설명 섹션
│   ├── ProjectModal/       # 프로젝트 모달 시스템
│   ├── Projects/           # 프로젝트 섹션
│   ├── Summary/            # 사이트 요약 설명 섹션
│   ├── TechModal/          # 기술 스택 모달 시스템
│   └── TechStack/          # 기술 스택 섹션
│   └── ValueFooter/        # 나의 핵심 가치와 푸터 섹션
├── constants/              # 프로젝트 데이터 및 설정값
└── asset/                  # 이미지, 아이콘, 폰트 리소스
```
